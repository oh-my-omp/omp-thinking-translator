# omp-thinking-translator

English | [简体中文](README.zh-CN.md)

- **Translator session lifecycle**
  - Session scope — Does: builds one translator per main interactive (TUI) session holding its cells, watched blocks, boxes and in-flight requests; subagents, print and RPC modes do nothing, and nothing is written to the session, model requests or compaction input. When: created on `session_start` and `session_switch`, disposed on `session_shutdown`. Example: `ctx.mode === "tui" && ctx.agent.kind === "main" ? createSession(pi, ctx) : undefined` in `index.ts`.
  - Line dispatch — Does: sends a thinking line for translation once it is final (a delta completes it, or the block ends) and the block has been drawn at least once, so hidden thinking is never sent anywhere. When: on `message_update` (thinking deltas, `thinking_end`), `message_end`, and the first draw of a block. Example: a streamed line `Let me check the hook order first.` is dispatched when its newline arrives.
  - Line filter — Does: translates a line only when, with inline-code spans removed, its Latin letters outnumber its CJK characters, so identifiers, paths and commands cannot make Chinese prose look foreign. When: for every final line before dispatch. Example: `` Read `src/session.ts` first `` is translated; `` 先读 `src/session.ts` 再改 `` is not.
  - Line keys and cells — Does: keys each translation by its line with a trailing `.`, `...` or `…` removed, so prose-only rewrites and reveal frames share one request; equal lines share one cell. When: at dispatch and at every draw. Example: `lineKey("Checking the config...")` → `Checking the config`.
- **Translator model role**
  - `@omp-thinking-translator` role — Does: the model role every translation uses, with ordered fallbacks from `retry.fallbackChains["omp-thinking-translator"]` and an optional `:level` thinking suffix per selector; unbound means no translation. When: resolved again at every attempt round. Example: bind in `/model` → "+ New role" to a `provider/id:off` selector; `/thinking-translator` lists the resolved chain.
  - Binding watch — Does: recomputes the cell key prefix (binding plus target language) and redispatches every drawn block when the binding, fallback chains or prose-only mode change; old translations stay cached for switching back. When: when `modelRoles`, `retry.fallbackChains` or `proseOnlyThinking` change. Example: switching the role to another model re-translates visible blocks.
  - Provider discovery — Does: discovers the providers the binding names once and resolves the chain again when the configured primary resolved to nothing. When: during a round whose chain is empty or replaced. Example: a proxy provider dropped from the registry after its cache expired is re-discovered.
- **Translation requests**
  - Translation prompt — Does: asks for a literal translation of only the text between markers, treated as inert data, keeping identifiers, paths, commands and error messages. When: for each dispatched line. Example: `You are a strict translation engine.` … `Translate ONLY the source text between SOURCE_TEXT_BEGIN and SOURCE_TEXT_END into Simplified Chinese.`
  - Marker guard — Does: aborts a response that echoes `SOURCE_TEXT_BEGIN`, checked while streaming, and rejects empty answers. When: during each streamed response. Example: error `Translator returned SOURCE_TEXT_BEGIN`, `Translator returned empty text`.
  - Retry rounds — Does: walks the chain from its first model, moves on only when a model fails, and after a whole-chain failure waits 500/2000/6000 ms and starts over; nothing remembers which model failed. When: per line until it succeeds or the delays run out. Example: after the last round the line becomes an error.
  - Failure and unbound notices — Does: shows a warning once per failing model set, and an info notice once when the role is unbound. When: when a line ends in error, or when translation is attempted with no binding. Example: `Thinking translation failed: …`, `thinking-translator: bind the @omp-thinking-translator model role in /model to translate thinking`.
- **Display**
  - Thinking renderer — Does: draws a translation box under each thinking block that only reads finished cells and never starts a request; history blocks get a one-off box only when some line already has a translation. When: whenever omp renders an assistant thinking block (`registerAssistantThinkingRenderer`). Example: ANSI box titled `done/total` with a Markdown body.
  - Tern surface — Does: on Tern's surface protocol returns a collapsible `section` shaped like omp's own thinking section, updating label and body in place. When: when a Tern surface calls `describe`. Example: the section follows omp's `expandThinkingBlocks` setting.
  - Late notifications — Does: sends translations that finish after their box left the redrawn area (retired to ANSI scrollback) as notification rows, after a 400 ms debounce, coalescing consecutive rows; never on Tern. When: when `lateNotify` is true and a finished cell was never painted. Example: `Thinking translation · Block 2` followed by the translated lines.
- **Settings and status**
  - Plugin settings — Does: `enabled` (default `true`), `targetLanguage` (default `Simplified Chinese`) and `lateNotify` (default `false`), read through `getPluginSettings`. When: read at session start and again at every `agent_start`. Example: `omp plugin config set omp-thinking-translator targetLanguage Japanese`.
  - `/thinking-translator` command — Does: shows the settings, the role binding, its fallbacks and the resolved model chain with reasoning levels, plus where diagnostics are logged. When: on `/thinking-translator`. Example: `role @omp-thinking-translator: …`, `models (tried in order, every request starts at 1):`, `diagnostics: debug records "thinking-translator: …" in ~/.omp/logs/omp.<date>.<pid>.log`.
  - UI language — Does: shows the command description, notices, box labels and status in English or Chinese. When: each time the text is produced. Example: `Thinking translation failed: ` / `思考翻译失败：`, chosen by `OMOMP_LANG`, then `LC_ALL`/`LC_MESSAGES`/`LANG`.
